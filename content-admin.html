Publicação de imagens na CDN

O navegador não deve guardar um token pessoal do GitHub. Por segurança, as imagens são preparadas em ZIP para publicação no repositório luaryshop/luary-cdn.

Estrutura esperada

luary-cdn/
├── categories/
├── home/
├── products/{SKU}/01.webp ... 10.webp
├── settings/
└── subcategorias/

Como publicar

  1. Use o Processador de Imagens para gerar o ZIP.
  2. Extraia o conteúdo mantendo os caminhos das pastas.
  3. Envie para o repositório GitHub luaryshop/luary-cdn.
  4. Aguarde a atualização do jsDelivr ou solicite purge do arquivo substituído.
Abrir processador de imagens
